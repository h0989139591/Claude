# 想轉職但不知道學什麼？

先不要急著報課，從這6個問題找到第二專長方向

很多人在40歲、50歲左右，甚至更早，就開始出現一個念頭：

「我是不是應該學一個第二專長？」

有些人是工作做久了，開始想轉換跑道。

有些人不是討厭現在的工作，只是開始思考：

「如果有一天離開現在的公司，我還會什麼？」

也有人看到：

瑜伽、

芳療、

NLP、

教練、

經絡、

健康產業，

覺得每一個都很有興趣，

結果反而不知道從哪裡開始。

如果你正處在這個階段，我第一個建議反而是：

# 先不要急著報課。

因為真正重要的不是：「現在市場上什麼最熱門？」

而是：「什麼方向適合你？」

## 

第一個問題｜我是想逃離現在，還是真的想走向下一個方向？

這兩件事情很不一樣。

如果只是因為：

工作壓力大、

主管不好相處、

收入不滿意、

最近特別累，

就急著換一個領域，

有時只是把現在的問題帶到下一個地方。

所以我常建議學生先問自己：

「如果現在工作突然變得順，我還會想學這個新專長嗎？」

如果答案仍然是：「會。」

那它比較可能是真正的興趣。

## 

第二個問題｜我是想自我成長，還是希望未來工作使用？

這也會影響課程選擇。

如果只是想：

了解自己、

改善生活、

增加興趣，

課程不一定要走到很深的專業訓練。

但如果未來希望：

教課、

開工作室、

提供服務、

進入企業、

發展第二職涯，

那就要進一步看：

課程深度、實作、考核、個案、專業倫理與後續學習。

所以：

# 先知道自己為什麼學，再決定要學多深。

## 

第三個問題｜我真正喜歡的是「內容」，還是「工作方式」？

這個問題很多人會忽略。

例如：

你喜歡芳療，

不代表你一定喜歡當芳療師。

你喜歡瑜伽，

也不代表你一定想每天站在教室前面教課。

你喜歡NLP，

也不一定表示你想做一對一教練。

所以要多問一層：

「如果未來真的靠它工作，我喜歡這種工作方式嗎？」

例如你比較喜歡：

- 一對一服務？

- 團體教學？

- 企業培訓？

- 自己開工作室？

- 線上教學？

- 把新專長和原本工作結合？

有時候真正要選的不是一門「知識」，

而是一種：未來想過的生活方式。

## 

第四個問題｜我過去的人生經驗，可以帶進來什麼？

很多40歲、50歲以後的人會說:「我現在才開始，是不是太晚？」

但我反而常看到另一件事：你並不是從零開始。

你可能已經累積：

管理經驗、

工程背景、

業務經驗、

家庭經驗、

照顧經驗、

教學經驗、

人生挫折與轉折。

這些東西不需要丟掉。

真正有價值的第二專長，往往不是：把第一人生全部歸零。

而是：把過去經驗帶進下一個專業。

## 

第五個問題｜我要的是第二張名片，還是第二種能力？

「第二專長」很容易被誤解成：「我要再拿一張證書。」

但證書只是其中一部分。

真正值得問的是：

「學完以後，我真正多了什麼能力？」

例如：

更會溝通、

更會教學、

更懂得帶領人、

更懂身體、

更懂精油安全、

更懂經絡、

更能設定與完成目標。

這些才是長期留在你身上的東西。

所以我一直相信：

# 學到真功夫，比拿到多少張證書更重要。

## 

第六個問題｜三年後，我希望別人怎麼介紹我？

這是一個我很喜歡的問題。

假設三年後，

有人問：

「你現在在做什麼？」

你希望自己怎麼回答？

也許是：

「我還在原本公司，但我也開始做企業內訓。」

或者：

「我退休之後開始教瑜伽。」

或者：

「我把芳療結合原本的美容工作。」

或者：

「我開始做NLP教練與溝通課程。」

當未來畫面比較清楚，今天要學什麼，通常就比較容易判斷。

# 

我自己50歲以前，也沒有一開始就知道答案

我自己也不是從電子業離開的第一天，就知道未來會走到今天。

35歲左右開始接觸經絡與NLP，

45歲學瑜伽，

後來又接觸芳療，

直到2011年，我才慢慢看見：

原來這些不同領域，可以被整理成一張完整地圖。

2012年才真正開始四合一。

所以我的經驗反而告訴我：

# 人生方向不是一次想清楚的，而是在學習與實踐中慢慢看清楚。

# 

如果你現在還不知道要學什麼

先不要急著選課。先回答六個問題：

- 我是真的想往前走，還是只想逃離現在？

- 我學這個，是興趣、自我成長，還是工作？

- 我喜歡的是內容，還是未來的工作方式？

- 我過去有哪些經驗可以帶進來？

- 我想增加的是證書，還是能力？

- 三年後，我希望自己成為什麼樣的人？

當這些答案比較清楚，課程反而比較好選。

# 先幫自己看懂，再讓自己決定。
